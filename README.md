# สนามสอบ ม.ต้น

ข้อสอบจำลอง ม.1–ม.3 แบบเกม สร้างห้องแล้วส่งลิงก์ให้เพื่อนเข้ามาแข่งกันทำได้พร้อมกัน

- 3 ระดับชั้น × 5 วิชา (คณิตศาสตร์ วิทยาศาสตร์ ภาษาไทย ภาษาอังกฤษ สังคมศึกษาฯ) วิชาละ 10 ข้อ รวม 150 ข้อ พร้อมเฉลย
- ข้อละ 20 วินาที ตอบถูกได้ 100 คะแนน ตอบเร็วได้โบนัสอีกสูงสุด 50 คะแนน
- อันดับสดระหว่างสอบ แท่นรางวัลตอนจบ และเฉลยทีละข้อ
- รีเฟรชหน้าแล้วกลับเข้าห้องเดิมได้ ถ้าเจ้าของห้องหลุด คนอื่นรับเป็นเจ้าของห้องแทนได้

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเกมทั้งหมด รวมคลังข้อสอบ (`BANK`) |
| `api/room.js` | Vercel Function จัดการห้อง ผู้เล่น และคะแนน |

ข้อมูลห้องเก็บใน Upstash Redis หน้าเว็บถามสถานะห้องทุก 1.5 วินาที ห้องหมดอายุเอง 3 ชั่วโมงหลังใช้งานครั้งสุดท้าย

## Deploy บน Vercel

1. เข้า [vercel.com/new](https://vercel.com/new) แล้ว Import repo นี้ ตั้ง Framework Preset เป็น **Other** ไม่ต้องตั้ง build command แล้วกด **Deploy**
2. เปิดโปรเจกต์ใน Vercel ไปที่แท็บ **Storage** → **Create Database** → เลือก **Upstash** → **Upstash for Redis** แผน Free แล้วกด **Connect** กับโปรเจกต์นี้
   Vercel จะเพิ่มตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง
3. ไปที่แท็บ **Deployments** กด **Redeploy** ที่ deployment ล่าสุด เพื่อให้ฟังก์ชันเห็นตัวแปรใหม่

ถ้าข้ามข้อ 2 หน้าเว็บจะขึ้นข้อความว่า “เซิร์ฟเวอร์ยังไม่ได้เชื่อมฐานข้อมูล”

ถ้าใช้ Upstash โดยตรง (ไม่ผ่าน Vercel) ให้ตั้ง `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` แทน

## รันบนเครื่อง

```bash
npm i -g vercel
vercel link
vercel env pull .env.local
vercel dev
```

## แก้หรือเพิ่มข้อสอบ

แก้ที่ `BANK` ใน `index.html` แต่ละข้อมีรูปแบบ

```js
["คำถาม", ["ตัวเลือก ก", "ตัวเลือก ข", "ตัวเลือก ค", "ตัวเลือก ง"], ลำดับข้อที่ถูก (0–3), "คำอธิบายเฉลย"]
```

แต่ละวิชาต้องมี 10 ข้อพอดี เพราะคะแนนเต็มกับหน้าผลสอบคิดจาก 10 ข้อ
